# 个人网站，是简历放不下的部分

个人网站很适合放简历装不下的东西：做项目的心路、博客，还有一些很难量化的软实力。不少 HR 看过我的网站，最多的反馈反而是“可以再多放点”。

现在有 AI，维护一个纯静态网页几乎没什么成本。写博客也顺便把学过的东西再消化一遍。

Yuniverse 已经开源：

- 网站：https://www.xinyuhuang.space/
- 源码：https://github.com/huangxinxinyu/Yuniverse

让 Codex 读一下代码，删掉我的静态资产、改几个字段，基本就能换成自己的。部署我选了 Vercel，连 GitHub repo、绑个域名就能上线，Hobby 对个人静态站够用了。
