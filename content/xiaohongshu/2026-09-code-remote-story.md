# 我把 Codex 终端带上了手机

状态：已发布（创作者后台已核验）

实际发布时间：2026-09-25 12:51（北京时间）

备选标题：为什么我做了 Code Remote｜手机遥控 Mac 上的 Codex

封面文案：出门也能看终端

## 正文

人离开 Mac 后，我还是想用手机看看 Codex 正在做什么。

我试过 Multica 等开源方案。发布任务、等待结果很方便；但碰到小任务，或者想盯着 agent 的工作过程时，我想直接看到原生 TUI，随时输入或处理确认。

所以我做了 Code Remote：用 iPhone Safari 经 Tailscale 连回自己的 Mac，操作 Codex 或 Claude Code 的原生终端。agent 仍在 Mac 上运行，tmux 会在手机断开后保留会话。

现在是可运行的开源原型。GitHub 搜索 `huangxinxinyu/CodeRemote`。
