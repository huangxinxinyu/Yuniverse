## 正文

这轮我继续调整 Code Remote 的显示和手机 UI，想让操作感觉更接近 Ghostty 加原生 Codex TUI。

现在可以直接看输出、从原生输入栏继续对话；`/` 菜单和 `/model` 选择器能在手机上操作，`/status`、`/permissions`、`/review` 也有快捷入口。

还可以新建、切换和结束多个终端，选工作目录开新终端，浏览并恢复 Codex 历史会话。重连和长连接场景仍在验收。

代码已开源。欢迎试用，遇到问题提 issue；想一起改也欢迎提 PR。GitHub 搜索 `huangxinxinyu/CodeRemote`。
